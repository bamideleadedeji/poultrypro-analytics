PoultryPro Analytics: Multi-Species Farm Enterprise Suite 🐓PoultryPro Analytics is a Python-based SaaS web application built with Streamlit for poultry farm managers, investors, and agricultural consultants. It provides unit economics modeling, real-time Feed Conversion Ratio (FCR) tracking, mortality financial impact adjustments, and batch feasibility auditing across multiple chicken species.🌟 Key FeaturesMulti-Species Support: Customized logic and default benchmarks for Broilers, Layers, Noilers, Cockerels, and Breeders.Dynamic Unit Economics: Automatically calculates break-even selling prices, overhead allocation, and production cost per surviving bird.FCR & Efficiency Engine: Computes feed consumption metrics against biomass gain and egg production target curves.Risk & Sensitivity Matrix: Generates side-by-side net profit stress tests under varying feed price shocks ($\pm10\%$) and mortality rates.Automated Reporting: Generates downloadable CSV raw data sheets and in-memory PDF executive audit reports.🛠️ Project StructurePlaintext├── app.py              # Main Streamlit web application & UI
